# OpenRealm Network Test

一个轻量美观的网络连通性测试页面，采用 Vercel 风格设计。

## 特性

- ✨ 现代化 Vercel 风格设计
- 🎨 深色主题与渐变光晕效果
- 🌊 丰富的动画效果（背景网格流动、光晕呼吸、卡片悬停等）
- 📱 完全响应式设计
- 🚀 轻量级单文件实现，无外部依赖
- ⚡ 实时延迟测量显示

## 使用

直接在浏览器中打开 `index.html` 即可使用。

或部署到任何静态托管服务：
- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages

## 页面说明

当用户能够访问此页面时，表示网络连接正常。页面会显示：
- 网络状态确认
- 模拟延迟测量
- 节点信息
- 连接状态

## 技术栈

- 纯 HTML + CSS + JavaScript
- 无框架依赖
- 现代浏览器支持
